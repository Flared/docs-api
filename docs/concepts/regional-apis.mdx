Flare is available in multiple regions. Each region has its own platform and API domain.

| Region | Platform | API |
| ------ | -------- | --- |
| US     | `https://app.flare.io` | `https://api.flare.io` |
| EU     | `https://eu.flare.io`  | `https://api.eu.flare.io` |

All endpoints, paths, and parameters described in this documentation are the same in every region.
Only the domain changes.

## Connecting to the EU API

If your organization uses the EU platform, generate your API key from the
[EU Profile page](https://eu.flare.io/#/profile) and send your requests to `https://api.eu.flare.io`.

<CodeGroup>

```bash cURL example
curl --request POST \
  --url https://api.eu.flare.io/tokens/generate \
  --header 'Authorization: <api-key>'
```

```python Python SDK
import os

from flareio import FlareApiClient


client = FlareApiClient(
    api_key=os.environ["FLARE_API_KEY"],
    api_domain="api.eu.flare.io",
)

resp = client.get("/tokens/test")

print(resp.json())
```
